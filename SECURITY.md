# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information issue within the Agape A.G. Church Guntakal website, please report it directly to the church administration team.

### Contact

- **Email**: `agapegtl@gmail.com`
- **Phone**: +91 98484 88414 / +91 95333 62164

Please include:
1. Description of the vulnerability.
2. Steps to reproduce the issue.
3. Relevant URLs or affected sections.

We appreciate the responsible disclosure of security issues and will investigate and patch any verified concerns promptly.
